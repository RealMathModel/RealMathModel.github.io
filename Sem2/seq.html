the whole idea

State is memory. The clock is the heartbeat.

A combinational circuit is a function: same inputs → same output, instantly. Add a flip-flop and the circuit gains a present state — so the same input can do different things depending on what came before. The clock decides when state is allowed to change.

Combinational
output = f(inputs)

No memory. A full adder always gives the same SUM for the same A, B, Cin. Chapters 1–4 lived here.

Y = f(X)
Sequential
output = f(inputs, present state)

Has memory in flip-flops. The next state is computed now but only latched on the clock edge. Chapters 5–6 live here.

Y = f(X, Q)  ·  Qnext = g(X, Q)

edge triggering

The edge is the moment.

An edge-triggered flip-flop samples its input only at the instant the clock rises (▲). Between edges the input can wiggle all it wants — nothing latches. Move the input line and watch: the output only steps at the rising edges.

design direction

Spec → circuit. Follow the recipe.

Design runs the other way: from a word problem to gates. The skeleton never changes — memorize the order like a recipe. Steps 5–6 are where your K-map skill and the excitation tables do the work.

State diagram / word spec. Translate the requirement into states and transitions.
State table. Present state + inputs → next state + outputs.
State reduction. Merge equivalent states so you don't build a bloated machine.
State assignment. Give each state a binary code → fixes how many flip-flops.
Excitation table. For each transition, look up the FF inputs (D, or J/K, or T…).
K-map each flip-flop input. Variables = all state bits and all external inputs. One map per input wire.
Draw the circuit. Wire the minimized input equations to the flip-flops.
The map-size rule. Every flip-flop input is a function of all present-state bits + all external inputs, so each K-map has (#flip-flops + #inputs) variables. And you draw one map per input wire: a D flip-flop has 1 input → 1 map; a JK has 2 (J and K) → 2 maps. Two JK flip-flops = four maps.
CHAPTER 6 · counters
ripple vs synchronous

Same count. Very different timing.

Both counters reach the same value — but watch how. In the ripple (asynchronous) counter each flip-flop clocks the next, so the change crawls left-to-right like a wave. In the synchronous counter every flip-flop shares the clock and flips at once. Press the pulse and watch the difference.

Ripple counter asynchronous

FF0 clocks FF1 clocks FF2… — carry ripples with delay.
value 0 · propagation visible left→right

Synchronous counter one clock

Every flip-flop shares the clock — all bits update together.
value 0 · all bits latch on the same edge
Why it matters: ripple is simpler to wire but its worst-case delay stacks up — n × tpd for n flip-flops — which caps the clock frequency (Problem 6.15). Synchronous costs more logic but every output settles together, so it runs faster and cleaner. That trade is the heart of Chapter 6.

circular counters

Ring & Johnson: shift registers that eat their own tail.

Feed a shift register's output back to its input and it counts by circulating a pattern. A ring counter walks a single 1 around (n states). A Johnson counter feeds back the inverted output, doubling the count to 2n states. Auto-run them and watch the patterns cycle.

Ring counter n states
One hot bit circulates: 1000 → 0100 → 0010 → 0001 → …
Johnson counter 2n states
Inverted feedback fills then empties: 0000→1000→1100→1110→1111→0111→…
Count the states: with 4 flip-flops a ring counter gives 4 states, a Johnson counter gives 8 = 2n (Problem 6.30). That's why Johnson counters are a cheap way to double your count without adding flip-flops.
mod-N

Any modulus: count, detect, reset.

A binary counter naturally counts to 2ⁿ. To make a mod-N counter you detect the moment the count hits N and force it back to 0. Drag the slider to set N and run it — the counter loops through exactly N states.

MODULUS N = 10
The recipe (Problem 6.22): a mod-N counter = a binary counter + a detector for state N-1 (or N) wired to the load, clear, or carry input. A NAND gate that fires on the terminal count and clears the flip-flops is the classic BCD (mod-10) trick.
